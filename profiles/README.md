# Community hardware catalogue

Each subdirectory is a versioned computer-model profile. Run `../ocp list` from
this directory, or `./ocp list` from the repository root. Create a new profile with
`./ocp capture --id <vendor-model-variant>` and review it before sharing.

The first included profile is `apple-macpro6-1` (Mac Pro Late 2013). Its status is
captured, not independently verified. See its README and manifest for exact
hardware, versions, settings, and outstanding warnings.
